## 四、关键教训沉淀（检查方 ↔ 答题方双视角）

1. **题面必须逐字匹配官方**：`question_text` 一字不差，否则官方 grader 按 0 分计（初版 23 条错配损失约 34 分）。
2. **官方 boolean 口径 = "年报是否提及"**（提及即 True），比"必须有当期实质事件"的严格校准更宽——6 道因口径反向的题修正后全部得分。
3. **官方 names GT 用逗号分隔**，提交用分号会 Jaccard=0；多答（期后事项）与漏答都失分。
4. **number 单位/口径**：原始值 vs 百万、期末 vs 平均、单期 vs 全年合计、科目差异——数据读对但提交格式不符会丢分。
5. **PDF 阅读范围**：只读前几页会漏掉后半部分 KPI（Aurora p9 "1,300 patents"、Albany p16 "2,300 patents" 都因"PDF 仅 N 页"误报而漏读）。
6. **文档一致性**：提交 value 与报告证据段要同步更新（报告残留 5 处 Syndax 旧表述）。

## 五、结论

**人式读文档方案经官方 round2 数据集完整验证：严格口径 92.26%、宽松口径 100%，可复刻、可迁移。** 与本发布包 round3/4/5 的成绩（69.35% / 75.81% / 85.71%）互相印证。
